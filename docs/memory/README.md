# Память проекта

Журнал для агентских сессий. Это не документация: архитектуру, стек и команды описывают
`README.md` и профильные документы, здесь — только то, чего в них ещё нет.

| Файл | Что держит | Как пишется |
|---|---|---|
| `progress.md` | Где проект сейчас, что дальше, что открыто | Переписывается целиком |
| `decisions.md` | Почему сделано так, что отвергнуто | Дописывается, с датой |
| `gotchas.md` | Ловушки, которые стоили времени | Дописывается, с датой |

Правила:

- **Не угадывать.** Запись фиксирует проверенное; «unverified» или молчание лучше уверенной ошибки.
- **Не дублировать.** Если факт уже в каноническом документе — ссылка на раздел, не копия.
- **Без кода.** Пути и номера строк вместо сниппетов.
- **Дата у каждой записи** — чтобы возраст был виден.
- `progress.md` — не больше экрана; история живёт в git.
- Решение, попавшее в канонический документ, помечается в `decisions.md` как
  `folded into <doc> §<n>`, а не удаляется.

Порядок чтения для новой сессии: `progress.md` → `decisions.md` (фильтр по области) →
`gotchas.md` → `AGENTS.md` той подсистемы, которую трогаешь.

Записывать после работы:

- состояние проекта изменилось → переписать `progress.md`;
- выбрал что-то, что иначе пере-решат → `decisions.md`;
- потратил на разгадку больше десяти минут → `gotchas.md`.
